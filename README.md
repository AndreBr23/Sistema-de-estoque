# Gestão PT — painel de estoque

Interface React/Vite pronta para publicação como aplicação estática na Vercel.

## Desenvolvimento local

\`\`\`bash
cd frontend
npm install
npm run dev
\`\`\`

## Publicar na Vercel

1. Envie este repositório ao GitHub/GitLab/Bitbucket.
2. Na Vercel, importe o repositório mantendo a raiz como diretório de trabalho.
3. A Vercel usará \`vercel.json\`: instala o frontend, gera \`frontend/dist\` e configura o fallback de rotas da SPA.

O painel atual usa dados demonstrativos. O backend Django pode ser publicado separadamente e conectado ao frontend via \`VITE_API_URL\`.
